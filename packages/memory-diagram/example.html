01 Stack, heap and pointers

A function keeps its local variables in its stack frame. Memory it asks for at run time lives on the heap, and a pointer variable holds the address of that memory, drawn as an arrow.

Nodes that point at each other make a chain. The last one is freed, so the pointer into it is dangling.
