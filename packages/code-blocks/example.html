01A listing

The marked line is the one the next paragraph talks about.

    #include <iostream>
    // Add the numbers 1..n.
    int total(int n) {
        if (n == 0) return 0;          // nothing left to add
        return n + total(n - 1);
    }

The same idea in another language:

    def total(n):
        """Add the numbers 1..n."""
        return 0 if n == 0 else n + total(n - 1)

Inline code can be coloured too: total(3) returns 6.
