01 Quoting the source faithfully

Source: Deck A, frames 3–5

Definitions and theorems keep the source's exact wording, in a quote with its citation:

A widget is a placeholder object that has exactly one handle.

Deck A, frame 3

A short phrase can be quoted inline: the source calls it the handle rule.

When the source attaches a note to its own content, such as a speech bubble on a slide, quote it in a source note:

Count the handles before you count anything else. Deck A, frame 4

Notes may add an intuition or an example the source does not give, and say so.

A longer addition, such as a worked example made up for these notes, goes in a block. Its label comes from the beyondBlockLabel option unless the block has its own .lbl.

The source states Theorem 2.1 as:

Every widget has two handles.

Deck A, frame 5

This contradicts the definition above; it should read exactly one handle.
