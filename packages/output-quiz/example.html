01 What does it print?

Read the loop, type the lines you expect it to print, one per line, and press Check (or Ctrl+Enter). Each line is marked; after three tries, or with Show answer, the expected lines appear next to yours.

Predict the output · Odd and even
      for (let i = 1; i <= 4; i++) {
        if (i % 2 === 0) console.log(i + " even");
        else console.log(i);
      }

02 Unlimited tries

This one allows as many checks as you like and shows the expected lines after every wrong check. Spacing inside a line is ignored, and so are blank lines.

Predict the output · A staircase
      for (int row = 1; row <= 3; row++) {
          for (int k = 0; k < row; k++) std::cout << "#";
          std::cout << "\n";
      }

03 What does it return?

The value variant has a one-line field. Every line of the expected block is an accepted answer, so quoted and unquoted forms can both count.

Predict the value · Repeat a tag
      def repeat(tag, times):
          return tag * times

      repeat("ab", 3)
