01 Password gate

With "password-gate": {} on and a password in .gate-password, every build also writes dist-gate/: this site inside a small Next.js app that asks for the password before it serves any page, image or script. Upload that folder to a Next.js host.

The folder holds a salted hash of the password, never the password itself, and every response tells search engines not to index it. Rebuilding with the same password keeps readers signed in.
