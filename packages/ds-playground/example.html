01 A growable array

A vector keeps its elements side by side in one array. Reading or writing a position is one step, but inserting near the front shifts every later element one place to the right. When the array is full, adding copies everything into a bigger one. Watch the counter: it counts every element moved.

02 Stacks and queues

A stack only lets you reach its top, like a pile of plates. A queue takes from the front and adds at the back, like a line at a counter. Every operation touches one element, however long they get.

03 Sets and maps

A set holds each value once; a map links each key to one value. Both are shown in sorted order, and a lookup halves the part still in question at every comparison, so even a long set needs only a few.

04 A priority queue on a heap

A binary heap is a complete tree stored in an array: the children of the entry at index i sit at 2i and 2i + 1. Each parent comes before its children, so the first entry is always at the root. A new entry starts at the end and bubbles up; taking the root moves the last entry up and lets it bubble down. Step through either one and count the swaps.

05 Linked lists

A linked list keeps each value in its own node, with a pointer to the next node. Adding at the front is one step. Reaching position i means walking i nodes from the head; step through and watch the cur pointer move.

Try it · A list of numbers

06 Binary search trees

In a binary search tree every key to the left of a node is smaller and every key to the right is larger. A search follows one path down, so its cost is at most the height, and the height depends on the order of the insertions.
