• Bernoulli trial: success with probability p, failure with 1 − p; indicator I has E[I] = p, Var(I) = p(1 − p).
  • Repeated trials: independent, same p every time.
  • Binomial X ~ Bin(n, p): P(X = k) = C(n, k) pk(1 − p)n−k, k = 0, …, n.
  • Indicators: X = I1 + ⋯ + In, so E[X] = np (linearity) and Var(X) = np(1 − p) (independence).
  • Geometric wait T: P(T = k) = (1 − p)k−1p, E[T] = 1/p, P(T > m) = (1 − p)m; memoryless.
  • Running proportion X/n: mean p, variance p(1 − p)/n.
  • Law of large numbers: P(|X/n − p| ≥ ε) → 0 for every ε > 0; the count gap X − np grows like √n.
  • Streaks are diluted, never corrected: a fair coin is never “due”.
