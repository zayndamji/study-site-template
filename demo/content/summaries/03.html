• Random variable: a function X : Ω → ℝ; {X = k} is an event.
  • PMF: p(k) = P(X = k) ≥ 0, summing to 1. Different variables can share a PMF.
  • Joint PMF p(x, y); marginal P(X = x) = Σy p(x, y). Marginals do not determine the joint PMF.
  • Independent: p(x, y) = P(X = x) P(Y = y) for every cell; one failing cell means dependent.
  • Expected value: E[X] = Σ k P(X = k); E[g(X)] = Σ g(k) P(X = k), but E[g(X)] ≠ g(E[X]) in general.
  • Linearity: E[X + Y] = E[X] + E[Y], E[aX + b] = aE[X] + b, with no independence needed.
  • Indicators: E[1A] = P(A). A count is a sum of indicators: a random shuffle of n items has 1 fixed point on average.
  • Variance: Var(X) = E[(X − μ)²] = E[X²] − μ²; SD = √Var; Var(aX + b) = a² Var(X).
  • Sums: if X, Y are independent, Var(X + Y) = Var(X) + Var(Y). Otherwise it can fail: Var(X + X) = 4 Var(X).
